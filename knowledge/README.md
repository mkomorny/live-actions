# Your Knowledge folder

Put your own notes and manuals here: `.md`, `.txt` or `.pdf`. Genius can find them by name with
`library_search` and open them with `library_read`.

This folder ships empty on purpose. Nothing in it is uploaded anywhere; when you ask Genius a
question, the parts of a file it opens are sent to the AI provider whose API key you entered, as
part of that conversation.

Optional: add an `INDEX.md` here. If it exists, Genius reads it at the start of every chat as its
map of your library, in place of the bundled one. A good index is a short table of
"if the question is about X, open file Y".

To use a different folder, change **Knowledge folder** in Preferences → Folders.
